# 数据整理与去重规则

## 选集结构化字段

当前实现为每个选集推导以下信息：

1. 主序号
2. 季信息
3. 内容类型
4. 分组键与分组名称
5. 清晰度标签
6. 编码标签
7. 格式标签
8. 语言标签
9. 来源标签
10. 标题规范化键

## 标题识别规则

### 主序号

按以下优先级提取：

1. `SxxExx`
2. `第X集 / 第X话 / 第X期 / 第X部`
3. `EP / E`
4. `Util.getNumber()`
5. 原始顺序索引回退

### 内容类型

按关键词识别：

1. 正片：默认
2. 剧场版：`剧场版`、`电影版`
3. 特别篇：`特别篇`、`特典`、`OVA`、`OAD`、`SP`
4. 花絮：`花絮`、`幕后`、`彩蛋`
5. 预告：`预告`、`先导`、`Trailer`、`PV`

### 版本标签

当前识别：

1. 清晰度：`4K`、`2160P`、`1080P`、`720P`、`480P`
2. 编码：`AV1`、`HEVC`、`H265`、`X265`、`H264`、`X264`
3. 格式：`M3U8`、`MKV`、`MP4`、`FLV`、`AVI`、`TS`
4. 语言：`国语`、`粤语`、`原声`、`中字`
5. 来源：`HDR`、`杜比`、`蓝光`、`WEB-DL`、`WEBRip`、`REMUX`

## 排序规则

排序键为：

```text
内容类型优先级
  -> 季
  -> 主序号
  -> 版本优先级
  -> 原始顺序
  -> 名称
```

## 倒序规则

1. 倒序只作用于当前分组的主内容序列。
2. 同一内容键下的多版本顺序保持稳定。
3. 不再对整条原始数组做粗暴 `reverse()`。

## 去重规则

### 真正重复

满足以下任一条件时去重：

1. 内容键相同且版本键相同
2. 内容键相同且 URL 相同
3. 内容键相同、版本键为空且展示文本相同

### 保留项

以下情况保留为独立入口：

1. 同一主序号但版本标签不同
2. 名称近似但内容类型不同
3. 动态补全后新增但未命中上述重复规则的项

## 历史兼容

续播匹配优先级为：

1. `episodeUrl` 精确匹配
2. 标题与主序号近似匹配
3. 当前线路已激活位置
4. 当前分组首项
