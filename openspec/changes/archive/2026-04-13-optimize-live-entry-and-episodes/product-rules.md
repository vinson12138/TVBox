# 产品规则说明

## 主页直播入口

1. 主页直播入口默认开启。
2. 直播入口显示条件统一为：

```text
LiveConfig.hasUrl() && Setting.isHomeLiveVisible()
```

3. 用户可在设置页手动关闭首页直播入口。
4. 关闭首页直播入口不会影响直播配置加载、直播页直接打开、外部导入直播源等能力。

## 选集组织

1. 选集优先按内容类型分组展示。
2. 分组优先级为：
   - 正片
   - 剧场版
   - 特别篇
   - 花絮
   - 预告
3. 同一集多版本优先折叠归类，不再简单依赖同名平铺。
4. 多版本信息优先以版本标签附着在选集项上，减少主选集区噪音。

## 手机端体验

1. 手机端详情页主选集区改为横向流动网格。
2. 当存在多个分组时，显示分组切换条。
3. “更多选集”保留为补充入口，默认展示当前分组的内容。

## 电视端体验

1. 电视端新增分组条。
2. 分组优先于分页条。
3. 分页条只作用于当前分组内的主序号序列。
4. 继续保留遥控器焦点优先的交互模型。
