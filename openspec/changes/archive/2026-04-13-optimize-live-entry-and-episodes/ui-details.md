# 交互说明

## 手机端

```text
线路
  -> 分组条（可选）
    -> 横向流动网格
      -> 当前集版本标签
```

### 行为

1. 线路切换时，优先按历史记录或当前选集推导默认分组。
2. 选集区改为横向 `GridLayoutManager`，竖向多行、横向流动。
3. 分组条仅在存在多个分组时显示。
4. “更多选集”与“控制栏选集列表”都只展示当前分组。
5. 倒序切换后，当前分组列表重新计算并保持当前集定位。

## 电视端

```text
线路
  -> 质量
    -> 分组条（可选）
      -> 选集条
        -> 分页条
```

### 行为

1. 新增独立的分组条，位于质量和选集之间。
2. 分组条仅在存在多个分组时显示。
3. 分页条继续存在，但只反映当前分组内的序列范围。
4. 焦点顺序更新为：`flag -> quality -> group -> episode -> array -> part -> quick`。
5. 切换分组时，选集条从当前分组首项开始，分页条同步更新。

## 版本展示

1. 版本信息通过选集项文本附加展示。
2. 已存在版本标签时不重复追加。
3. 版本信息仅作为识别与浏览辅助，不改动播放器质量切换区的职责。
